# Мониторинг АЗС

Отдельная платформа (решение Тимура 27.10.2026): экран для руководства — проверки ОСК и отзывы посетителей. С Джарвисом не связана, его базу не нагружает.

- Данные ОСК — Google Таблица «ОСК — сеть» (шаблон: `~/Downloads/ОСК_сеть.xlsx`, листы и колонки менять нельзя — экран читает их по названиям).
- Отзывы — админка https://review.asko-plus.ru (только чтение: вход, список отзывов; телефоны клиентов не берём).
- Своей базы нет: данные держатся в кеше Cloudflare 2 минуты.
- Расчёты (`src/calc.js`) — как в бланке ОСК: процент смены — среднее процентов 7 пунктов, за месяц — среднее смен, шкала взысканий и штраф управляющего из листа «Настройки». Проверка на станции А-2 — `node tests/calc.test.mjs`.

Секреты (вводит Тимур, в чат не присылать): `npx wrangler secret put SHEET_ID | MONITOR_PASS | REVIEW_LOGIN | REVIEW_PASSWORD`.
Проверка подключения без данных: `/api/health`.
